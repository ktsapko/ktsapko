### 🚀 Featured Project

**[STM32 Sensor Hub](https://github.com/ktsapko/Stm32SensorHub)**

Bare-metal C++20 firmware for the STM32F401RE (ARM Cortex-M4), built without HAL or an RTOS.

Features include:

- Custom peripheral drivers using memory-mapped registers
- I²C sensor integration (BMP280, MPU-6050)
- SH1106 OLED dashboard with live sensor measurements
- Interrupt-driven USART communication and DMA-based transmission
- SysTick scheduling, I²C bus recovery, and native unit tests
